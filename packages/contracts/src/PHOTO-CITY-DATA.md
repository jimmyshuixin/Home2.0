# Offline photo city approximation

`photo-city-data.ts` is a compact, latitude-sorted gazetteer for `approximatePhotoCity`.
It is shared by the authenticated administrator UI and the publication boundary.
There are no geocoding requests, API keys, subscriptions or runtime data downloads.

## Provenance

- Publisher: Natural Earth; **10m populated places, version 5.1.2**.
- Official description: https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-populated-places/
- License: public domain, https://www.naturalearthdata.com/about/terms-of-use/
- Pinned source: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_populated_places.geojson
- Retrieved: 2026-09-27.
- Source bytes: 19,359,003; source features: 7,342.
- Source SHA-256: `9b8e3de09048ef00dfc70357dbb9fa324493f214b5e0ae4daf1aa79a8d10116b`.
- Generated bytes: 193,212; selected places: 4,966.
- Generated SHA-256: `14b038c09ea56ebb7bfd2b4c1978ab7fef2cd8d1356c0e3674ba977b7cff8e07`.

Selection includes populated places with `POP_MAX >= 50000`, plus administrative
capital point features at levels 0 or 1 (including region and alternative capitals).
Historic places, meteorological stations and scientific stations are excluded.
Rows retain only Point geometry latitude/longitude and `NAME_ZH`, falling back to
`NAME_EN` then `NAME`. Coordinates are the upstream place point, not capture GPS.
Rows are sorted by latitude, longitude and label for a bounded candidate scan.

Reproduce after downloading the pinned source to a local file:

```sh
node packages/contracts/scripts/generate-photo-cities.mjs /path/to/ne_10m_populated_places.geojson
```

The generator refuses a different source checksum. Updating the version therefore
requires a deliberate data and provenance review; builds do not silently refresh it.

## Meaning and privacy boundary

- A valid capture coordinate can select the nearest included city point within
  **75 km** great-circle distance. This is a coverage cutoff, not a promised minimum
  distance from the capture site or an anonymity radius.
- The returned label always ends in `附近` (nearby). Natural Earth supplies map
  place points, not city boundary polygons. The result cannot prove administrative
  city membership and may select a neighbouring city, including across a border.
- The output coordinate is always one of the fixed included place points, never
  rounded capture GPS. Multiple photos assigned to a city share that same point.
- Missing/invalid GPS, remote areas and gaps in the dataset return `undefined`.
  There is no exact-coordinate fallback. Administrators may correct a city or hide it.
- Small administrative capitals are retained even when below the population cutoff.
  Nearest-place assignment cannot guarantee a minimum geographic privacy area,
  particularly around dense neighbouring cities; it only removes capture precision.
- Do not infer locations from album titles, descriptions, upload times or IP address.
- Keep exact capture GPS in private metadata. The public map receives only the
  explicit per-photo publication projection and this selected city point.

The data is a static 2026 retrieval of the named release, not a live authoritative
administrative gazetteer. Its coverage and names inherit Natural Earth's limitations.
