# Home2.0

一个前后端分离的个人网站雏形。它不是传统博客，而是一本可以翻页的生活手账：桌面端像摊开的书，同时看两页；移动端像拿在手里的单页；后台则是一个可以写字、贴图、贴胶带的画板编辑台。

## 技术栈

- 前端：Vue 3 + Vite
- 后端：Node.js + Express
- 结构：`frontend/` 与 `backend/` 分离
- 形态：H5 响应式页面，当前面向浏览器，保留微信小程序平台适配口
- 风格：手写字体、纸张纹理、胶带贴图、书签、目录、封面
- 游戏：图片素材驱动的 H5 小游戏，接住掉落贴纸，把素材贴进手账

## 本地运行

```bash
npm install
npm run dev
```

前端默认运行在 `http://localhost:5173`，后端默认运行在 `http://localhost:8787`。

## 目录

```text
frontend/          Vue3 手账阅读器与画板编辑台
backend/           Express 内容 API
docs/              设计概念图与项目说明资料
```

## H5 与小程序升级口

当前实现是 H5：`#home` 是前台阅读页，PC 展示摊开的双页书，移动端自动收为单页；`#studio` 是 PC 后台画板编辑台；`#game` 是图片素材版手账贴贴乐小游戏。浏览器能力通过 `frontend/src/platform/runtimePort.js` 收口，包括请求、缓存、图片读取、ID 生成和画布导出。日后升级微信小程序时，可以用同文件中的 `createWechatMiniProgramPort(wx)` 替换 H5 port，再把页面组件迁移到小程序视图层。

## 已实现的第一版体验

- 公开阅读页：手账书翻页、封面、目录、书签、桌面双页和移动单页适配
- 创作画板：添加手写便签、上传图片、贴胶带、贴纸、画笔涂写
- H5 小游戏：使用 PNG 背景、PNG 贴纸精灵图和 PNG 接物手账，不使用 CSS 多边形拼视觉主体
- 内容保存：画板内容可提交到后端 API，后端以 JSON 存储页面数据
- 视觉方向：不使用常规卡片网格，尽量以纸张、贴纸、书脊和书签构成布局

后续可以接入用户登录、真实图片对象存储、富文本/图层持久化、Cloudflare Pages + Workers 部署等。
